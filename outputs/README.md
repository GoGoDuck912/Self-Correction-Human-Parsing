# Output Results

Processed human parsing segmentation results will appear here.

## Output Format:

- PNG images with color-coded segmentation
- Same filename as input with .png extension

## Example:

```
outputs/
├── person1.png (segmented version of inputs/person1.jpg)
├── person2.png (segmented version of inputs/person2.png)
└── group_photo.png (segmented version of inputs/group_photo.jpeg)
```

Each color represents different body parts or clothing items depending on the model used.
